## English

A self-hosted web panel for managing proxy cores on your Linux server. Create connections and share access with friends through links, QR codes and subscriptions. Built for personal use.

The project is under active development. The panel uses Jaspr, the backend uses Dart Frog, and data is stored in SQLite. Services run through systemd.

## Русский

Веб-панель для управления прокси-ядрами на своём Linux-сервере. Создавай подключения и делись доступом с близкими через ссылки, QR-коды и подписки. Для личного использования.

Проект в активной разработке. Панель написана на Jaspr, бэкенд на Dart Frog, данные хранятся в SQLite. Службы работают через systemd.
